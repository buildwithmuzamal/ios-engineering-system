# Repository Standards

## Purpose

This document defines the engineering standards used throughout this repository.

---

# 1. Repository Philosophy

- Documentation First
- One Source of Truth
- Learn → Build → Document → Review
- Think Before You Build

---

# 2. Folder Rules

- Every folder has exactly one responsibility.
- Do not create random folders.
- Every major folder must include a README.md.
- Use existing folders whenever possible.

---

# 3. Documentation Rules

- Never duplicate information.
- Every concept has one permanent note.
- Use templates whenever available.
- Every document must be reachable from the root README.
- Documentation should be easy to scan.
- Use relative links for internal navigation.

# 9. README Standards

Every README should answer:

- What is this?
- Why does it exist?
- How should it be used?
- Where should I go next?

README Rules

- Keep paragraphs short.
- Avoid duplicate explanations.
- Use internal links.
- Make navigation obvious.
