# Indie Developer Tool Ideas Roadmap
## Beginner → Advanced

> **Purpose**
>
> Build useful tools that solve real problems for developers and everyday users.
>
> Every tool should:
>
> - Solve one specific problem well.
> - Be publishable.
> - Teach practical engineering skills.
> - Be reusable in future projects.
> - Take days or weeks to build, not months.

---

# Roadmap Philosophy

Follow the 80/20 rule:

- Build small.
- Ship quickly.
- Solve one problem.
- Learn one new concept.
- Reuse what you've already learned.
- Improve the tool over time.

The first 10 tools should be completable in a short time and reinforce the iOS fundamentals you'll use every day. Later tools introduce more advanced frameworks and engineering challenges while remaining useful to both you and other users.
