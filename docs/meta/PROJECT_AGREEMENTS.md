# PROJECT_AGREEMENTS.md

# iOS Engineering System — Project Agreements

This document contains the agreed architecture and rules for this project.

The purpose of this file is to ensure that any future ChatGPT conversation follows the same vision and does not redesign, simplify, or ignore previous decisions.

---

# Primary Goal

Build a complete Engineering Learning System that takes an intermediate iOS developer to top-level engineering skills through project-based learning.

The goal is NOT to create a simple roadmap.

The goal is to build an Engineering Operating System.

---

# Repository

Repository:

ios-engineering-system

This repository is:

- Engineering curriculum
- Knowledge base
- Public documentation
- Open source project
- Engineering portfolio

Everything should be written in Markdown.

Everything should be GitHub friendly.

Eventually the repository will be published using GitHub Pages.

The repository is the single source of truth.

---

# Learning Philosophy

Never teach using a purely linear roadmap.

Instead, every module must contain multiple learning layers.

Learning should feel like real engineering work.

Theory should always be followed by practice.

Everything should build toward production-quality engineering.

---

↓

Review

↓

The layers below are continuous.

They are NOT standalone modules.

# Final Objective

The objective is not merely to learn Swift or get a job.

The objective is to become an engineer who can:

- Build production-quality products
- Launch independent businesses
- Read and understand any iOS codebase
- Learn new technologies independently
- Make sound engineering decisions
- Mentor other developers
- Stay valuable as technology and AI evolve
