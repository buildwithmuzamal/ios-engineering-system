# Phase 04 --- Professional App Architecture

## Goal

Move from writing working code to designing maintainable systems.

## Learning Outcomes

-   Organize projects.
-   Design maintainable features.
-   Understand architectural trade-offs.
-   Build modular apps.

## Module 1 --- Project Organization

Core: Folder structure, feature organization, separation of concerns.

Layers: - Git: Feature branch workflow - Xcode: Groups vs folders -
Apple Docs: App architecture guidance - Best Practices: One
responsibility per file - Design Thinking: Why organization matters

## Module 2 --- MVVM

Core: Model, View, ViewModel, responsibilities. Layers: Pull Requests,
Thin Views, MVVM trade-offs.

## Module 3 --- Dependency Injection

Core: Constructor injection, protocols, dependency inversion.

## Module 4 --- SOLID Principles

SRP, OCP, LSP, ISP, DIP.

## Module 5 --- Clean Architecture

Domain, Data, Presentation, dependency direction.

## Module 6 --- Modularization

Swift Package Manager, reusable modules.

## Module 7 --- Tuist

Targets, Schemes, Configurations.

## Module 8 --- Architecture Decision Making

Evaluate trade-offs and technical debt.

## Phase Project

Refactor an existing SwiftUI app into a production-style project using
MVVM, DI, SOLID, SPM/Tuist and document architectural decisions.

## Exit Criteria

-   Organize large projects.
-   Explain architecture decisions.
-   Apply MVVM and DI.
-   Build modular codebases.
