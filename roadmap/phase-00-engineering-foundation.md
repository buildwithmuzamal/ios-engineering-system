# Phase 00 --- Engineering Foundation

> **Purpose:** Build the engineering habits, workflow, and tools that
> will support every later phase.

------------------------------------------------------------------------

# Goal

Before mastering Swift or SwiftUI, become comfortable with the daily
workflow of a professional iOS engineer.

------------------------------------------------------------------------

# Learning Outcomes

By the end of this phase you should be able to:

-   Work confidently with Git basics.
-   Navigate Xcode efficiently.
-   Read Apple documentation.
-   Debug simple problems.
-   Keep structured engineering notes.
-   Use AI to learn instead of copy.
-   Follow a repeatable engineering workflow.

------------------------------------------------------------------------

# Modules

## Module 0.1 --- Engineering Mindset

### Core Topic

-   What is Software Engineering?
-   Learning philosophy
-   Problem solving
-   Engineering workflow

### Parallel Learning Layers

**Git** - What is Git? - Install & configure - init - clone

**Xcode** - Interface tour - Navigators - Quick Help - Documentation
viewer

**Apple Documentation** - Learn how to navigate developer.apple.com -
Read your first documentation page

**WWDC** - Learn what WWDC is and how to use it

**Best Practices** - Consistency over speed - Read before coding

**Design Thinking** - Solve problems before writing code

**AI** - Ask for explanations - Never copy blindly

**English** - Learn common engineering vocabulary

**Notes** - Create first permanent Markdown notes

**Reflection** - Why do professional engineers work differently?

------------------------------------------------------------------------

## Module 0.2 --- Git Foundations

Core: - status - add - commit - log - restore

Layers: - Xcode Source Control - Commit message best practices - GitHub
repository creation - Markdown README

Project: Create your Engineering System repository.

------------------------------------------------------------------------

## Module 0.3 --- Xcode Fundamentals

Core: - Project navigator - Search - Breakpoints - Console - Debug
Area - Quick Help

Layers: - Apple Docs for Xcode - Keyboard shortcuts - Productivity tips

Practice: Explore an existing sample project.

------------------------------------------------------------------------

## Module 0.4 --- Documentation & Research

Core: - Apple Documentation - Swift Documentation - Searching APIs -
Reading examples

Practice: Research an unfamiliar API using only official documentation.

------------------------------------------------------------------------

## Module 0.5 --- Debugging Basics

Core: - Reading compiler errors - Runtime errors - Breakpoints - print
vs debugger

Practice: Debug intentionally broken code.

------------------------------------------------------------------------

## Module 0.6 --- Engineering Notes

Core: - Markdown - Repository structure - Linking notes - Writing for
future you

Deliverable: Write notes for every completed module.

------------------------------------------------------------------------

# Phase Project

Create your public **ios-engineering-system** repository with: -
README - Roadmap - Notes folder - First documentation - Proper Git
history

------------------------------------------------------------------------

# Exit Criteria

You are ready for Phase 01 when you can:

-   Use Git without fear.
-   Navigate Xcode confidently.
-   Find information in Apple Documentation.
-   Debug basic issues.
-   Maintain organized notes.
-   Explain your engineering workflow.
