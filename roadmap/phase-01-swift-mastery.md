# Phase 01 --- Swift Mastery

> **Purpose:** Master the Swift language deeply before focusing on
> advanced frameworks. Build strong fundamentals that support every
> future phase.

------------------------------------------------------------------------

# Goal

Become confident writing idiomatic Swift and understand *why* the
language works the way it does.

------------------------------------------------------------------------

# Learning Outcomes

By the end of this phase you should be able to:

-   Write clean, idiomatic Swift.
-   Understand value vs reference semantics.
-   Explain ARC and memory management.
-   Use protocols and generics effectively.
-   Write asynchronous code with async/await.
-   Read Swift documentation independently.

------------------------------------------------------------------------

# Module 1 --- Swift Basics

### Core Topic

-   Variables & Constants
-   Data Types
-   Operators
-   Control Flow
-   Functions

### Parallel Learning Layers

**Git** - status - add - commit - .gitignore

**Xcode** - Code completion - Quick Help - Build & Run - Fix-It
suggestions

**Apple Documentation** - The Swift Programming Language (Basics)

**WWDC** - None unless needed

**Best Practices** - Meaningful naming - Small functions - Avoid magic
numbers

**Design Thinking** - Why type safety matters

**AI** - Ask AI to explain concepts, not generate solutions.

**English** - Variables, constants, function, parameter, return value.

**DSA** - Big-O notation introduction. - Constant vs Linear time.

**Practice** - Small Swift exercises.

**Challenge** - Build a console calculator.

**Notes** - Permanent Markdown notes.

**Reflection** - What advantages does Swift provide over less type-safe
languages?
