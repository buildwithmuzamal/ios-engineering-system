# Phase 01 — Swift Mastery

> **Purpose:** Master the Swift language deeply before focusing on advanced frameworks. Build strong fundamentals that support every future phase.

---

# Goal

Become confident writing idiomatic Swift and understand *why* the language works the way it does.

---

# Learning Outcomes

By the end of this phase you should be able to:

- Write clean, idiomatic Swift.
- Understand value vs reference semantics.
- Explain ARC and memory management.
- Use protocols and generics effectively.
- Write asynchronous code with async/await.
- Read Swift documentation independently.

---

# Module 1 — Swift Basics

## Core Topics

- Variables & Constants
- Data Types
- Operators
- Control Flow
- Functions

---

## Learning Objectives

After completing this module you should be able to:

- Understand Variables & Constants and recognize when it is the right tool.
- Understand Data Types and recognize when it is the right tool.
- Understand Operators and recognize when it is the right tool.
- Understand Control Flow and recognize when it is the right tool.
- Understand Functions and recognize when it is the right tool.
- Apply the module concepts in the mini project without copying a full solution.
- Use official documentation as the primary reference for this module.

---

## Parallel Learning Layers

### Git

- Commit after each small Swift exercise.
- Use branches for experiments.
- Keep .gitignore accurate for Xcode projects.

### Xcode

- Code completion
- Quick Help
- Fix-It
- Build and run

### Apple Documentation

- The Swift Programming Language — chapters for this module

### WWDC

- Swift language sessions only when they strengthen this module

### Best Practices

- Prefer clarity when working with Variables & Constants.
- Keep responsibilities small and names meaningful.
- Validate understanding with a working example before moving on.

### Design Thinking

- What problem does Variables & Constants solve?
- What would a simpler alternative look like?
- What trade-offs appear if this is overused?

### Architecture Thinking

- Where does this concept belong in a production app?
- What should stay out of the UI layer?
- How would this decision affect testing and change later?

### Open Source

- Read a small Swift package focused on these language features

### AI

- Ask AI to explain Variables & Constants after you attempt it yourself.
- Request a review of your design, not a full generated solution.
- Challenge AI suggestions against Apple documentation.

### English

- Write a short explanation of Variables & Constants in your own words.
- Use precise terminology in notes and commit messages.
- Practice explaining trade-offs as you would in a pull request.

### Notes

- Document Variables & Constants, Data Types, Operators, Control Flow.
- Capture common mistakes and Apple recommendations.
- Link related modules and future spiral topics.

### Reflection

- Can I teach Variables & Constants to another engineer?
- What is still unclear?
- How does this connect to previous phases?

---

## Mini Project

- Build a console calculator using functions, operators, and control flow.
- Keep the scope small enough to finish, but realistic enough to reuse later.
- Document one design decision and one mistake you corrected.

## Exit Criteria

You should be able to:

- Use Variables & Constants correctly in a realistic scenario and explain the trade-offs.
- Use Data Types correctly in a realistic scenario and explain the trade-offs.
- Use Operators correctly in a realistic scenario and explain the trade-offs.
- Use Control Flow correctly in a realistic scenario and explain the trade-offs.
- Finish the mini project and describe one design decision you made.
