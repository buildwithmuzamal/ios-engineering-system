# Phase 03 --- Apple Frameworks

> **Purpose:** Learn Apple's frameworks by solving real-world problems
> instead of studying APIs in isolation.

------------------------------------------------------------------------

# Goal

Understand when, why, and how to use Apple's frameworks while developing
production-quality applications.

------------------------------------------------------------------------

# Learning Outcomes

By the end of this phase you should be able to:

-   Select the right framework for a problem.
-   Read framework documentation confidently.
-   Integrate Apple frameworks into SwiftUI apps.
-   Understand framework trade-offs.
-   Build apps using multiple Apple technologies.

------------------------------------------------------------------------

### Parallel Learning Layers

**Git** - Rebase basics

**Xcode** - Documentation Quick Help - Symbol Navigator

**Apple Documentation** - Foundation Framework

**WWDC** - Foundation updates (when relevant)

**Best Practices** - Prefer Foundation types over reinventing solutions.

**Design Thinking** - Why Foundation exists.

**AI** - Compare Foundation APIs, not generate implementations.

**English** - Framework, API, Serialization, Locale
